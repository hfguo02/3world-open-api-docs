# 请求与响应规范

## 请求

JSON 请求使用 `Content-Type: application/json`；申请材料上传使用 `multipart/form-data`。请求签名必须使用实际发送的原始请求体。

## 普通响应

## 普通响应

```json
{
  "success": true,
  "code": "200",
  "msg": "Success",
  "data": {}
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `success` | boolean | 请求是否成功 |
| `code` | string | 业务响应码；成功为 `200` |
| `msg` | string | 响应描述 |
| `data` | object / array / boolean / null | 业务数据 |

## 分页响应

分页响应包含 `code`、`msg` 和 `data`，其中 `data` 的结构如下：

```json
{
  "pageNo": 1,
  "pageSize": 20,
  "totalPage": 1,
  "totalCount": 1,
  "data": []
}
```

分页响应不包含 `success`。鉴权失败、参数错误和限流等异常响应包含 `code` 与 `msg`，具体含义见[错误码](../reference/error-codes.mdx)。
