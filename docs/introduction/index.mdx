# 环境与地址

## 环境

| 环境 | Base URL |
| --- | --- |
| Sandbox | `https://label.3worldglobal.com/wapi` |
| Production | 由 3World 提供 |

## 接入凭证

向 3World 获取 `Partner ID`、`API Key` 和 `API Secret`。`API Secret` 仅存储在服务端，不要写入前端代码、日志或客户端应用。

每个 API 请求都需要使用这些凭证完成鉴权签名，具体规则见[鉴权签名](/introduction/authentication-signature)。
