# 3World 白标卡服务接入指南

白标商户可通过 3World API 完成卡片申请与管理、账户授信、余额与交易查询，并通过 Webhook 接收业务状态通知。

## 当前版本

**V2** 是新接入的默认版本，包含 V2 接口以及尚未被替代的 V1 接口。

维护现有 V1 集成时，从顶部版本栏打开 **V1**。单次集成请勿混用 V1 和 V2 文档。

## 接入路径

1. 阅读<Link to="/introduction/quickstart">快速开始</Link>并准备测试环境。
2. 按<Link to="/introduction/authentication-signature">鉴权签名</Link>生成请求头与签名。
3. 从 <Link to="/api">API 文档</Link> 选择业务模块并实现接口。
4. 配置 <Link to="/webhooks">Webhook 事件</Link>，接收异步状态通知。
5. 根据<Link to="/introduction/common-responses">通用响应</Link>和<Link to="/reference/error-codes">错误码</Link>处理接口结果。
