# 快速开始

## 环境

| 环境 | Base URL |
| --- | --- |
| Sandbox | `https://dev.3worldglobal.com/wapi` |
| Production | 不对外公开 |

## 接入前提

3World API 不使用登录 Token，而是使用 `Partner ID + API Key + API Secret` 对每个请求签名。请先向 3World 获取这三项凭证，并确保 API Secret 只保存在服务端。

## 第一个请求

下面的请求查询当前合作伙伴可申请的卡产品。签名字段中的 `path` 必须使用实际请求路径，`body` 为空字符串。

```bash
curl --request GET \
  --url https://dev.3worldglobal.com/wapi/openapi/application/v2/products?pageNum=1\&pageSize=20 \
  --header 'X-Partner-Id: YOUR_PARTNER_ID' \
  --header 'X-API-Key: YOUR_API_KEY' \
  --header 'X-Timestamp: CURRENT_UNIX_TIMESTAMP_MS' \
  --header 'X-Request-Id: UNIQUE_REQUEST_ID' \
  --header 'X-Signature: HMAC_SHA256_SIGNATURE'
```

`X-Signature` 的计算方式见[请求签名](./request-signing)。API 页面中的代码用于复制和集成，不会在浏览器内发送真实请求。

## 推荐接入流程

1. 调用产品列表接口，保存可用的 `productCode`。
2. 调用 V2 申请接口创建申请单。
3. 按 KYC 证件类型上传申请资料。
4. 通过申请查询接口或 Webhook 获取申请状态。
5. 通过卡片接口查询卡片、激活、冻结或解冻。

下一步阅读[认证方式](./authentication)、[请求签名](./request-signing)和[通用响应](./common-responses)，然后进入 [API 文档](../api)。
