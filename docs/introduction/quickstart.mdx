# 快速开始

## 接入前提

先完成[环境与地址](/introduction)和[鉴权签名](/introduction/authentication-signature)中的准备工作。

## 第一个请求

以下请求查询商户可申请的卡产品。计算签名时，`path` 使用实际请求路径，GET 请求的 `body` 为空字符串。

```bash
curl --request GET \
  --url https://label.3worldglobal.com/wapi/openapi/application/v2/products?pageNum=1\&pageSize=20 \
  --header 'X-Partner-Id: YOUR_PARTNER_ID' \
  --header 'X-API-Key: YOUR_API_KEY' \
  --header 'X-Timestamp: CURRENT_UNIX_TIMESTAMP_MS' \
  --header 'X-Request-Id: UNIQUE_REQUEST_ID' \
  --header 'X-Signature: HMAC_SHA256_SIGNATURE'
```

按[鉴权签名](./authentication-signature)生成 `X-Signature`。

## 接入流程

1. 调用产品列表接口，保存可用的 `productCode`。
2. 调用申请接口创建申请单。
3. 按 KYC 证件类型上传申请资料。
4. 通过申请查询接口或 Webhook 获取申请状态。
5. 通过卡片接口查询卡片、激活、冻结或解冻。

完成首个请求后，继续查阅[请求与响应规范](/introduction/common-responses)和 [API 文档](/api)。
