# Webhooks

> 通过 Webhook 实时接收业务事件通知。

Webhook 允许你在事件发生时立即收到通知，例如交易状态变更、风控触发等。相比轮询，Webhook 更及时且对服务端压力更小。

## 工作机制

当有事件发生时，平台会向你在后台配置的回调地址发送 HTTP POST 请求。你需要准备一个可公网访问的 HTTPS 端点接收这些请求。

## 配置 Webhook

1. 登录接入方后台
2. 进入「Webhook 配置」页面
3. 填写回调地址并选择订阅的事件类型
4. 保存后配置即时生效

## 处理回调请求

收到回调后，请按以下顺序处理：

<Steps>
  <Step title="校验签名">
    使用平台提供的公钥校验请求签名，确认请求来源可信。
  </Step>

  <Step title="解析事件内容">
    解析事件负载，提取事件类型与业务数据。
  </Step>

  <Step title="返回成功响应">
    处理成功后返回 HTTP 200，避免平台重试投递。
  </Step>
</Steps>

<Note>
  回调请求支持重试机制。请确保你的端点幂等，避免重复事件导致重复处理。
</Note>

## 常见问题

- **收不到回调**：检查回调地址是否可公网访问、签名校验是否通过、事件类型是否订阅。
- **重复投递**：平台按投递策略重试，请保证处理逻辑幂等。
