# 错误码

以下为白标 OpenAPI 实际可能返回的错误码。请求失败时响应体包含 `code` 与 `msg`，其中 `code` 为业务响应码，成功为 `200`。

## 通用错误

所有接口均可能返回：

| code | 含义 |
| --- | --- |
| `200` | Success |
| `600001001` | Parameter error |
| `600001003` | Signature verification failed |
| `600001004` | Timestamp expired |
| `600001006` | IP not in whitelist |
| `600001008` | Request rate limit exceeded |
| `600001009` | Internal server error |
| `600001010` | Missing required header |
| `600001011` | Partner ID format invalid |
| `600001012` | Invalid API Key format |
| `600001013` | API Key does not match Partner ID |
| `600001014` | Replay request detected |
| `600001015` | System error, please try again later |
| `600001016` | Partner does not exist |
| `600001017` | Partner is disabled or deleted |

## 说明

- 鉴权、签名和参数校验类错误（`600001xxx`）返回 HTTP `401`；限流 `600001008` 返回 HTTP `429`。
- 拦截器兜底异常返回 `600001000`（系统错误），该码未收录于错误码枚举。
- 个别异常路径可能直接返回内部错误码（如 `500000002`、`500007003`），以接口实际返回为准。
