# Overview

> Victoria 开发者文档平台。基于 Docusaurus 构建，支持多语言、多产品线、多版本结构，并集成 OpenAPI 生成可交互的 API 参考文档。

本平台面向接入 Victoria 开放能力的开发者，提供从接入引导、接口说明到调试的全流程文档。

## 开始之前

接入前请准备：

- 有效的接入方账号与 API 凭证
- 选择对接环境（沙箱 / 生产）
- 阅读 [快速接入](/guide/quickstart) 了解基本流程

## 文档结构

| 区域 | 路径 | 说明 |
| --- | --- | --- |
| 指南 | `/guide/*` | 手写接入引导文档，含步骤与示例 |
| API 参考 | `/api/passkey/*` | 由 OpenAPI 规格自动生成，可交互调试 |

### 多语言

站点默认英文，通过右上角语言切换可切换到中文。指南与 API 参考均支持 `en` / `zh` 两种语言。
