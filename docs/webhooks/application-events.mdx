# 申请事件

事件分类：`APPLICATION`

| 事件类型 | 说明 |
| --- | --- |
| `application.submitted` | 申请已提交 |
| `application.approved` | 申请已通过 |
| `application.rejected` | 申请已拒绝 |
| `application.cancelled` | 申请已取消 |

## 事件数据（`data`）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `uid` | string | 商户侧用户 UID |
| `applicationId` | string | 申请单 ID |
| `status` | string | `SUCCESS` / `FAIL` / `PROCESSING` / `CANCELLED` / `DRAFT` |
| `cardId` | string | 卡片 ID，可为空 |
| `reason` | string | 原因，可为空 |
| `changedAt` | string | ISO-8601 时间 |
