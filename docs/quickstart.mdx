# Quickstart

> 在几分钟内完成首次 API 调用。

本指南带你完成从准备环境到发起第一个请求的完整流程。

## 前提条件

开始之前，请确保你已准备：

- 一个接入方账号
- API 凭证（客户端 ID 与密钥）
- 已配置允许的调用来源 IP

## 认证与调用 API

<Steps>
  <Step title="获取访问令牌">
    使用你的凭证请求获取访问令牌。

    ```bash
    curl -X POST https://api.example.com/api/v1/connect/token \
      -H "Content-Type: application/json" \
      -d '{"clientId": "YOUR_CLIENT_ID", "clientSecret": "YOUR_CLIENT_SECRET"}'
    ```

    <Note>
      访问令牌有效期有限，过期后需重新获取。生产环境建议通过服务端保存并定时刷新。
    </Note>
  </Step>

  <Step title="调用业务接口">
    携带令牌调用业务接口。

    ```bash
    curl -X GET https://api.example.com/api/v1/user/getInfo \
      -H "Authorization: Bearer YOUR_ACCESS_TOKEN"
    ```

    <Note>
      所有业务接口均需在请求头携带访问令牌。具体接口说明见 [API 参考](/api/passkey/overview)。
    </Note>
  </Step>
</Steps>
