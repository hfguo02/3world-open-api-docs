本次 Passkey 接入前后端对接的**全部接口**，按用途分 4 组，标注【新增】/【修改】/【历史复用】及使用时机。每个出入参均标注枚举值与精简含义。

通用约定：
- 鉴权：除登录组外，请求头带 `3world-token: {tokenValue}`。
- 响应统一包裹 Result，`code="200"` 成功；命中风控时 code 非 200 且 risk 携带风控单。
- 二级认证(safe)唯一开启入口是 `/security/verify`(openSafe)，`@SaCheckSafe` 校验，靠同一登录 token 关联。
- 高风险业务验证：verify/start、verify/finish 传 riskConsoleNo=风控单写回模式(本次新增)；不传=safe 模式。
