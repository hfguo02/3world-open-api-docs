# 授信事件

事件分类：`CREDIT`

| 事件类型 | 说明 |
| --- | --- |
| `credit.adjustment.accepted` | 授信请求已接受 |
| `credit.adjustment.success` | 授信调整成功 |
| `credit.adjustment.failed` | 授信调整失败 |

## 事件数据（`data`）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `uid` | string | 商户侧用户 UID |
| `orderNo` | string | 授信单号 |
| `outOrderNo` | string | 商户业务单号 |
| `amount` | number | 授信金额 |
| `currency` | string | 币种 |
| `changedAt` | string | ISO-8601 时间 |
| `errorCode` | string | 失败事件的错误码，可为空 |
