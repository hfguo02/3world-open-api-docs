# 快速开始

## 环境

| 环境 | Base URL |
| --- | --- |
| Sandbox | `https://label.3worldglobal.com/wapi` |
| Production | 由 3World 提供 |

## 接入前提

向 3World 获取 `Partner ID`、`API Key` 和 `API Secret`，并将 `API Secret` 仅存储在服务端。每个 API 请求均须使用这三项凭证完成鉴权签名。

## 第一个请求

以下请求查询商户余额。计算签名时，`path` 使用实际请求路径，GET 请求的 `body` 为空字符串。

```bash
curl --request GET \
  --url https://label.3worldglobal.com/wapi/openapi/account/v1/partner/balance \
  --header 'X-Partner-Id: YOUR_PARTNER_ID' \
  --header 'X-API-Key: YOUR_API_KEY' \
  --header 'X-Timestamp: CURRENT_UNIX_TIMESTAMP_MS' \
  --header 'X-Request-Id: UNIQUE_REQUEST_ID' \
  --header 'X-Signature: HMAC_SHA256_SIGNATURE'
```

按[鉴权签名](./authentication-signature)生成 `X-Signature`。

## 现有集成维护流程

1. 按 V1 API 文档核对现有调用路径和字段。
2. 保持签名原文与实际发送的请求完全一致。
3. 使用申请查询和 Webhook 跟踪异步状态。
4. 使用卡片、账户和交易接口维护已有业务。
5. 新增能力前评估迁移到 V2，不在同一流程中混用两个文档版本。

完成首个请求后，继续查阅[通用响应](./common-responses)和 [API 文档](../api)。
