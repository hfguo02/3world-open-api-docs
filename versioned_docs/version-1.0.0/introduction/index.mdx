# 3World 开发者文档

3World 白标卡服务为合作伙伴提供卡片申请、卡片管理、账户授信、余额查询、交易查询和 Webhook 通知能力。文档按实际对接流程组织：先完成认证和签名，再按业务模块查阅 API，最后配置异步事件通知。

## 当前版本

你正在查看 **V1 历史文档**。本版本用于维护既有 V1 接入，不建议新项目从这里开始；新接入请返回顶部版本栏的 V2 文档。

V1 与 V2 是两套完整的文档上下文。一次对接应始终以同一个版本为准，不要从 V2 页面补充或替换本页接口。

## 接入路径

1. 阅读[快速开始](./introduction/quickstart)并准备测试环境。
2. 配置[认证方式](./introduction/authentication)和[请求签名](./introduction/request-signing)。
3. 从 [API 文档](./api) 选择业务模块并实现接口。
4. 按需配置 [Webhook 事件](./webhooks) 接收异步状态变化。
5. 联调时结合[错误码](../reference/error-codes)排查问题。
